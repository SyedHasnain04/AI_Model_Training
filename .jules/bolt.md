## 2025-03-09 - Performance Optimization: NumPy Lookup Table (LUT) for Mask Conversion
**Learning:** Replaced multiple boolean mask assignments (O(N) * num_classes) with a NumPy LUT. Cached the mapping dictionary as a function attribute and performed a single indexing operation. It is safer to do `arr = np.where((arr >= 0) & (arr <= 10000), arr, 0)` before indexing the LUT instead of `np.clip` to prevent `IndexError`s and ensure that out-of-bounds values map safely to the background class 0. This provided a ~6x speedup.
**Action:** When working on pixel-value-to-label mapping, use a NumPy lookup table (LUT) cached as a function attribute instead of multiple boolean mask assignments for better performance. Ensure bound safety by using `np.where((arr >= 0) & (arr <= MAX_VAL), arr, 0)` before indexing.
