## 2025-06-05 - NumPy Lookup Table (LUT) for Mask Conversion
**Learning:** In pixel-value-to-label mapping tasks (like `convert_mask`), chaining multiple boolean masks (`arr==val`) iterates over the image arrays multiple times and creates intermediate arrays, resulting in O(N*C) operations (where N is the number of pixels and C is the number of classes).
**Action:** Use a cached NumPy Lookup Table (LUT) array to achieve O(N) vectorized mapping. By storing the mapping at indices and using array indexing (`lut[arr]`), you can replace boolean comparisons. To handle potential out-of-bounds array values in real-world data gracefully, use `np.where((arr >= 0) & (arr <= MAX_VAL), arr, 0)` rather than `np.clip` before indexing the LUT. This safely forces unseen high or negative pixel values to 0 (the background class) without falsely labeling them as the max valid class, preventing `IndexError` while maintaining correctness.
