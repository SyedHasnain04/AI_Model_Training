## 2024-05-18 - Optimized Mask Conversion using Cached NumPy LUT
**Learning:** In Jupyter Notebook environments where functions like `convert_mask` are repeatedly called for every image in a dataset (e.g., during training/testing via PyTorch DataLoaders), multiple boolean mask assignments (`arr == value`) are a major bottleneck. NumPy array creation and boolean masking take significant time, especially for high-resolution images (512x512).
**Action:** Replace multiple boolean mask assignments with a pre-computed NumPy Lookup Table (LUT) cached as a function attribute (e.g., `if not hasattr(convert_mask, 'lut'): ...`). Ensure bound safety by using `np.where((arr >= 0) & (arr <= MAX_VAL), arr, 0)` before indexing to prevent out-of-bounds `IndexError`s. This pattern can result in an ~6x speedup.
