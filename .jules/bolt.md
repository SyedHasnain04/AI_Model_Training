## 2024-05-14 - Optimize `convert_mask` with LUT
**Learning:** The `convert_mask` function in `randoms_(1).ipynb` uses 10 sequential boolean mask assignments on a NumPy array (e.g., `new_mask[arr==100]=1`). This creates multiple intermediate boolean arrays and is quite slow, especially for high-resolution images or large datasets. Because the label values are discrete integers in a small range [0, 10000], it is possible to use a NumPy lookup table (LUT) mapping directly to labels.
**Action:** When performing pixel-value-to-label mapping in masks, use a NumPy lookup table (LUT) cached as a function attribute instead of multiple boolean mask assignments for better performance. Ensure bound safety by using `np.where((arr >= 0) & (arr <= MAX_VAL), arr, 0)` before indexing the LUT to safely map out-of-bounds values to 0 (background) and prevent `IndexError`s.
