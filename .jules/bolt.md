## 2024-05-24 - Jupyter Notebook convert_mask O(1) Lookup Optimization
**Learning:** Found an inefficient pixel-value-to-label mapping inside `convert_mask` taking O(N) comparisons over large 512x512 matrices because of multiple boolean assignments per label. Using a NumPy lookup table (LUT) cached as a function attribute provides significant performance improvements by shifting from multiple O(N) boolean mask operations to a single O(1) vectorized indexing step. When memory allows, always use LUTs over multiple boolean array masking for discrete categorical mapping. Need to `np.where` bounds check first to prevent `IndexError`.
**Action:** Always search for sequential array boolean assignments like `new_mask[arr==X]=Y` and replace them with a cached NumPy LUT attribute to maximize throughput in high-frequency data loading functions, prioritizing safety via bound checking.
