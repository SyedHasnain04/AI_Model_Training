## 2024-06-13 - O(N) Metric Calculations in PyTorch and NumPy
**Learning:** In pixel-dense segmentation tasks, calculating per-class intersection and union using boolean masks inside a loop (`(pred==cls)&(mask==cls)`) results in O(C*N) complexity. Replacing this with a 1D confusion matrix using `torch.bincount(mask * NUM_CLASSES + pred)` changes the complexity to O(N), bringing massive speedups to the `mean_iou` function. Similarly, mapping pixel values via successive boolean array indexing (`arr==val`) is O(V*N). Using a cached NumPy lookup table (LUT) and indexing `lut[arr]` reduces this to O(N).
**Action:** When calculating metrics or converting pixel values in image masks, default to `torch.bincount` and cached NumPy LUTs rather than looping and/or repeated boolean masking arrays.
