## 2024-05-29 - Vectorized LUT indexing vs Boolean Masking for Segmentation Mask Conversion
**Learning:** In segmentation mask preprocessing (like `convert_mask`), using multiple sequential boolean mask assignments (e.g., `new_mask[arr==100]=1`) is significantly slower than using a pre-allocated NumPy Lookup Table (LUT). The LUT method provides O(1) vectorized indexing for all pixels simultaneously instead of checking the array conditions iteratively. However, when using LUTs, bound safety is critical (`arr_safe = np.where((arr >= 0) & (arr <= 10000), arr, 0)`) to prevent `IndexError` when pixels outside the expected range are mapped. `np.clip` shouldn't be used for out-of-bounds mapping since it could map unknown pixels to valid highest classes incorrectly.
**Action:** When converting segmentation masks (pixel-value-to-label mapping), always replace sequential boolean assignments with a cached NumPy LUT while ensuring bound safety using `np.where`.
