## 2024-05-21 - Vectorized mean_iou and LUT mask conversion in Segformer notebook
**Learning:** In PyTorch, computing class-wise intersection and union iteratively using boolean masks (e.g. `(pred==cls)&(mask==cls)`) is a major performance bottleneck for segmentation models, especially for large image sizes (like 512x512) and batch processing. The old method loops `NUM_CLASSES` times over tensors. Using `torch.bincount` to build a confusion matrix reduces operations to a single pass and computes metrics in parallel, dramatically improving calculation time (approx. 5x faster).
**Action:** Always favor vectorized, confusion matrix-based IoU computation using `torch.bincount` over iterative boolean masking for semantic segmentation metrics. Ensure to cast masks and predictions to `torch.long` and handle out-of-bound labels safely before building the confusion matrix.
