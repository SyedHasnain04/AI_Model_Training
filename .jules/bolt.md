## 2024-05-24 - Mask conversion using LUT instead of boolean masking in Python/NumPy
**Learning:** In Jupyter notebook computer vision workflows that map specific pixel values to class labels (like [0, 100, 200...] to [0, 1, 2...]), using sequential boolean array indexing (e.g. `new_mask[arr==100]=1`) creates intermediate boolean arrays for every single assignment, which scales poorly for large images like 512x512.
**Action:** When converting segmentation masks, build a single NumPy lookup table (LUT) array of size max_value + 1 (cached as a function attribute) and use direct array indexing `lut[arr]` with bound-safety (`np.where`), reducing complexity from O(K * N) to O(N) where K is the number of classes and N is the number of pixels. This provides a significant speedup in the dataloader critical path.
