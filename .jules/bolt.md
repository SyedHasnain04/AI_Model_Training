## 2024-06-25 - Static LUT for Pixel Value Mapping
**Learning:** For label mapping across large semantic segmentation mask tensors (e.g. converting 10 classes in 512x512 images), relying on sequential boolean masking (`new_mask[arr==X]=Y`) introduces extreme overhead because it makes C (number of classes) passes over N pixels (O(C * N)). Using a static, cached lookup table (LUT) via array indexing provides massive speedups (O(N)), reducing inference/loading overhead by 6x.
**Action:** When mapping pixel intensity values to semantic classes in arrays, avoid multiple boolean assignments. Instead, create a static numpy array LUT sized to the max possible value (e.g., `lut = np.zeros(10001)`) and map the entire array in one index operation. Ensure memory safety using `np.where((arr >= 0) & (arr <= max_val), arr, 0)` instead of `np.clip` (which would incorrectly map out-of-bounds large values to the highest class index).
