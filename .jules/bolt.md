## 2024-06-14 - Optimize Numpy Array Lookups in Masks
**Learning:** In the `randoms_(1).ipynb` notebook, mask conversion was performed using 10 separate boolean masking passes (e.g. `new_mask[arr==100]=1`) which is extremely inefficient when loading dataset batches. Replacing this with a NumPy Lookup Table (LUT) mapped via advanced indexing `convert_mask.lut[arr]` reduced mask conversion time by over 5x. However, note that `lut[arr]` is technically an O(N) operation over the pixels, not strictly O(1), even though it reduces the constant factor massively. Out-of-bounds safety requires `np.where((arr >= 0) & (arr <= 10000), arr, 0)` rather than `np.clip` to avoid erroneously mapping massive invalid values to the top valid label.
**Action:** Use cached NumPy LUT arrays combined with safe `np.where` bound-checking for mapping pixel labels instead of multiple sequential boolean masks.
