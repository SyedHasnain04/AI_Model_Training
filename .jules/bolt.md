## 2026-05-27 - Vectorized mIoU and cached LUT mask conversion in PyTorch notebook
**Learning:** In a PyTorch offroad segmentation notebook, naive loop-based IoU calculation (O(N_classes * Image_size) with many boolean tensor operations) and multiple consecutive boolean array assignments in mask conversion are major performance bottlenecks during training/eval. `torch.bincount` is significantly faster for mIoU.
**Action:** When performing pixel-value-to-label mapping in masks, use a NumPy lookup table (LUT) cached as a function attribute instead of multiple boolean mask assignments. For high-performance vectorized `mean_iou` calculation in PyTorch, use `torch.bincount` to build a confusion matrix; cast mask and prediction tensors to `torch.long` before computing indices (e.g., `mask * NUM_CLASSES + pred`) to prevent overflow and explicitly filter out-of-range mask values to maintain metric accuracy.
